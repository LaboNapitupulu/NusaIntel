# NusaIntel interface direction

Existing identity: warm paper, deep green ink, editorial serif headings. Retain it while removing the rotating cube, tilt effects, inflated claims, and repeated slogans.

Reading this as: a public-data workspace for Indonesian analysts and readers, with a restrained editorial style, ENERGY 1 / RHYTHM 2 / MOTION 1. This direction follows the existing palette and type, and the early decision to focus on tables, sources, and status.

- Palette: off-white surfaces and teal actions; status colors only indicate real status. Dark mode shares the same semantic tokens.
- Type: existing Inter for controls and data, DM Serif Display for page titles and the text wordmark. Tabular numerals help comparisons.
- Layout: a two-column task directory on the home page; compact configuration beside results where space allows; full-width reading areas for sources.
- Containers: equal directory links reflect four equally available tasks; bordered panels separate configuration, evidence, and results rather than decorate every text block.
- Icons: plain labels; no decorative brand badge. The theme symbol accompanies a visible label.
- Spacing: 4/8/12/16/24/32/40/48px rhythm; borders divide content without turning every paragraph into a card.
- Motion: 140ms control feedback only, disabled with reduced-motion preferences. Data values appear at their actual values.

ENERGY 1 / RHYTHM 2 / MOTION 1. Quiet reference work benefits from stable data, varied reading density, and direct feedback.
